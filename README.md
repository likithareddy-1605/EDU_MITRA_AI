# 🎓 EduMitra AI
### AI-Enabled Family Decision-Support Platform for Engineering Education

**Empowering Student Success & Family Alignment**

EduMitra AI is an AI-powered educational decision-support platform designed to help engineering students make informed academic and career decisions while enabling meaningful collaboration between students and their parents.

The platform brings together academic tracking, AI-powered educational assistance, engineering course guidance, career exploration, study planning, and family decision support in one place.

EduMitra AI aims to bridge the communication gap between students and parents by encouraging transparent academic planning, personalized guidance, and collaborative decision-making.

🌐 **Live Website:** https://edumitraai-pi.vercel.app

💻 **GitHub Repository:** https://github.com/likithareddy-1605/EDU_MITRA_AI

## 📖 About the Project

Choosing the right engineering course, managing academic responsibilities, planning a career, and maintaining communication between students and parents can be challenging.

Students may struggle to identify suitable academic pathways, understand their progress, organize their study schedules, and explore career opportunities. Parents may also find it difficult to support educational decisions without clear information about their student's goals and progress.

EduMitra AI addresses these challenges through an integrated platform that combines artificial intelligence, academic planning, career guidance, and student-parent collaboration.

The platform provides dedicated experiences for students and parents while supporting educational planning through AI-assisted recommendations and structured decision-making tools.

### Our Vision

To create a supportive educational ecosystem where students, parents, and AI work together to improve academic planning, career awareness, and educational decision-making.

### Our Mission

To make engineering education guidance more accessible, personalized, transparent, and collaborative through AI-powered technology.

---

## ❗ Problem Statement

Engineering students face multiple challenges while making academic and career decisions.

Some of the common challenges include:

- Difficulty identifying suitable engineering courses and academic pathways.
- Limited access to personalized academic guidance.
- Uncertainty about career opportunities and future professional goals.
- Difficulty organizing study schedules and tracking academic goals.
- Communication gaps between students and parents regarding educational progress.
- Challenges in comparing educational alternatives before making important decisions.
- Limited availability of integrated platforms that combine academic assistance, career guidance, and family collaboration.

These challenges can make educational planning confusing for students and their families.

EduMitra AI aims to address these problems through an integrated AI-enabled decision-support platform.

---

## 💡 Our Solution

EduMitra AI provides a centralized platform for academic assistance, engineering course guidance, career exploration, study planning, and student-parent collaboration.

The platform combines role-based dashboards, AI-powered assistance, personalized onboarding, academic goal management, and family decision-support features.

Instead of treating academic planning, career guidance, and parental involvement as separate activities, EduMitra AI brings these capabilities together in one application.

The goal is to help students understand their options, organize their goals, and make more informed decisions with appropriate family support.

## 🚀 Key Features

The Student Dashboard serves as the student's central workspace for academic planning and educational guidance.

Key capabilities include:

- Personalized student experience.
- Access to academic guidance tools.
- Academic progress and goal tracking.
- Study planning and organization.
- Student profile management.
- Access to engineering course recommendations.
- Access to AI-powered academic assistance.
- Career exploration and planning.

The dashboard helps students organize their educational activities and access relevant features from one place.

### 2. 👨‍👩‍👧 Parent Dashboard

EduMitra AI provides a dedicated dashboard for parents to support their student's educational journey.

Key capabilities include:

- Parent-specific dashboard experience.
- Student-parent relationship management.
- Access to student information according to applicable permissions.
- Support for educational discussions and planning.
- Visibility into shared academic information.
- Collaboration around educational goals and decisions.

The platform is designed to support family involvement while respecting student privacy and information-sharing permissions.

The AI Academic Advisor integrates Google Gemini to provide AI-assisted educational guidance.

Potential uses include:

EduMitra AI provides family decision-support capabilities intended to encourage constructive discussions about educational alternatives.

Key objectives include:

- Supporting collaborative educational planning.

## ⚙️ Installation and Setup

Follow these instructions to run EduMitra AI locally.

### Prerequisites

Install the following:

- Node.js and npm.
- Git.
- A code editor such as Visual Studio Code or Antigravity.
- A Supabase project.
- A Google Gemini API key if you want to use the AI features.

### Step 1: Clone the Repository

Open a terminal and run:

```bash
git clone https://github.com/likithareddy-1605/EDU_MITRA_AI.git
```

### Step 2: Navigate to the Project

```bash
cd EDU_MITRA_AI
```

### Step 3: Install Root Dependencies

```bash
npm install
```

### Step 4: Install Frontend Dependencies

```bash
npm --prefix client install
```

### Step 5: Install Backend Dependencies

```bash
npm --prefix server install
```

### Step 6: Configure Environment Variables

Create the environment files required by the frontend and backend.

Use the existing `.env.example` files and project configuration to identify the required variable names.

Do not commit secret credentials to GitHub.

### Step 7: Start the Application

Start the frontend using:

```bash
npm --prefix client run dev
```

Start the backend in a separate terminal:

```bash
npm --prefix server run dev
```

The exact local URLs and any additional setup requirements depend on the project's current configuration.

## 🔑 Environment Configuration

EduMitra AI relies on environment variables for external services and application configuration.

Depending on the current implementation, these may include:

| Environment Variable | Purpose |
|---|---|
| `VITE_SUPABASE_URL` | Supabase project URL used by the frontend |
| `VITE_SUPABASE_ANON_KEY` | Public Supabase key used by the frontend |
| `SUPABASE_URL` | Supabase project URL used by the backend |
| `SUPABASE_SERVICE_ROLE_KEY` | Privileged Supabase server-side access, if required |
| `GEMINI_API_KEY` | Google Gemini API access, if required by the backend |

Use the exact variable names expected by the existing source code and `.env.example` files.

### Important Configuration Notes

1. Use the Supabase project root URL.
2. Do not append `/rest/v1` to the Supabase project URL.
3. Keep secret keys out of frontend code.
4. Never upload `.env` files containing credentials to GitHub.
5. Configure the required variables in Vercel for production deployment.
6. Use the public anonymous key only for client-side operations intended to use that key.
7. Keep privileged service-role credentials exclusively on the server.

Example of the expected Supabase project URL format:

```text
https://YOUR_PROJECT_ID.supabase.co
```

Replace the placeholder with your actual Supabase project URL.

## 🔐 Security and Privacy

Security is important because EduMitra AI handles educational information and supports student-parent collaboration.

The application is designed with the following considerations:

- Authentication for user access.
- Separate student and parent experiences.
- Role-aware application workflows.
- Controlled sharing of student information.
- Server-side handling of privileged credentials.
- Environment variables for sensitive configuration.
- Supabase database access policies.

### Privacy Considerations

Student information should only be accessible to authorized users according to the application's permissions.

Parent access should respect the configured student-parent relationship and applicable sharing controls.

### Security Recommendations

- Never expose service-role keys in frontend bundles.
- Never commit private API keys to source control.
- Configure Supabase Row Level Security policies appropriately.
- Validate permissions on the server or database, not only in the UI.
- Rotate credentials if they are accidentally exposed.
- Review authentication and access-control behavior before production use.

Security depends on the actual implementation and deployment configuration.
